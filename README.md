# Arabidopsis RNA-seq Differential Expression Analysis

## Objective
Identify differentially expressed genes associated with stress treatment in *Arabidopsis thaliana*.

## Dataset
- **GEO Accession:** GSE146206
- **Organism:** *Arabidopsis thaliana*
- **Analysis:** Mannitol vs Control

## Workflow
1. Data loading and preprocessing
2. Exploratory quality control and PCA
3. Differential gene expression analysis using DESeq2
4. Volcano and MA plot visualization
5. Gene Ontology enrichment analysis

## Tools
R, Google Colab, DESeq2, ggplot2, clusterProfiler.

## Validation
Sample labels and count-data handling must be verified against the original study before interpreting biological findings.
